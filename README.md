# hhll-coupon

クーポン案内ページ(ハハロルオンラインクリニック)

## 目的

LINE公式アカウント「ハハロルオンラインクリニック」の配信から開く、3ステップのご案内ページです。
気になっていること・お電話番号・希望の時間帯を入力して「確認へ進む」を押すと、入力内容が受付担当(社内の連絡ツール)に届き、カウンセラーからクーポンとご予約の手続きについてお電話します(受付は毎日10:00〜20:00、土日祝も受付)。
最後に、選んだ内容が入った文をLINEのトーク画面に用意し、ご本人がLINEで送信します(クーポンのご案内が届き、お申し込みの控えになります)。
クーポンの内容と条件(総額・通常価格・解約の条件など)は、ページの見出しのすぐ下に表示します。

## LINEのトークに入る文の形

```
#初月無料クーポン申込_MD
気になること:3 受診条件
連絡先:090-0000-0000
希望時間:夕方以降(17〜20時)
```

1行目は、LINE公式アカウントで自動のご案内を返すための合言葉です。

## 送信する内容

「確認へ進む」を押し、電話番号の形と同意のチェックが通った時点で、次の内容を受付担当へ1回だけ送信します(戻って内容を変えた場合は、もう一度「確認へ進む」を押した時点で送り直します。送った内容と違うまま確認の画面には進みません)。送信の成否にかかわらず画面は次へ進み、LINEでの送信が控えになります。

| 項目 | 内容 |
|---|---|
| `type` | 診療の種類(`md` / `aga`) |
| `concernNo` / `concernShort` | 気になっていること(番号と短い語) |
| `phone` | お電話番号(ハイフン区切りに整えたもの) |
| `time` | 希望の時間帯(`any` / `am` / `pm` / `ev`) |
| `uid` | URL の `uid` パラメータ(英数字・`-`・`_` の64文字まで。それ以外やなしは空) |
| `sid` | ページを開くたびに作る無作為の識別子(16進32文字)。同じ画面から番号や種類を直したことを見分けるために使います。ページを開いている間のメモリにだけ持ち、端末・ブラウザの履歴・URL には入れません |
| `ts` | 送信した時刻 |
| `v` | ページの版 |
| `hp` | 機械的な送信を見分けるための見えない欄(通常は空) |

- 送信にはGoogleのサービス(Googleフォーム)を使います。上の項目を1つのJSON文字列にして、フォームの1つの欄に入れて送ります(`https://docs.google.com/forms/d/e/…/formResponse` へ `application/x-www-form-urlencoded` で POST)
- 送信先はこのGoogleフォームだけです(CSP で `connect-src https://docs.google.com` に限定、`form-action 'none'`)
- 送信先が未設定の版(`FORM_ACTION` か `FORM_ENTRY` のどちらかが空)と、識別子を作れない端末では、何も送信しません(LINEでの送信が控えになります)

## このページがしないこと

- お電話番号は端末に保存しません(ページを開いている間だけ使います)。画面を戻ったときに続きから選べるよう、選んだ項目の番号だけをブラウザの履歴に持ちます。Cookie・localStorage・sessionStorage は使いません
- 上の送信先のほかには通信しません。外部スクリプト・外部フォント・解析タグは読み込みません。検索エンジンには載せません(`noindex`)
